## 📚 Core Topics Covered

1. **Foundations of AI & Intelligent Agents:**
   - Agent architectures, PEAS (Performance, Environment, Actuators, Sensors) classification.
   - Deterministic vs. Stochastic, Static vs. Dynamic environments.

2. **Problem Solving & State-Space Search:**
   - **Uninformed Search:** Breadth-First Search (BFS), Depth-First Search (DFS), Uniform-Cost Search.
   - **Informed (Heuristic) Search:** Greedy Best-First Search, A* Search algorithm, admissibility and consistency of heuristics.

3. **Adversarial Search & Games:**
   - Minimax algorithm, Alpha-Beta pruning, evaluation functions.

4. **Knowledge Representation & Logic:**
   - Propositional logic, inference rules, resolution.
   - First-Order Predicate Logic (FOL), quantifiers, unification.

5. **Probabilistic Reasoning & Machine Learning Basics:**
   - Bayes' Theorem, Bayesian Networks, conditional independence.
